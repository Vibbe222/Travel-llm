## 当前行为说明

### Redis 正常启动时

- 工具查询优先读取 Redis 缓存；
- 工具成功结果写入 Redis TTL 缓存；
- LangGraph checkpoint snapshot 写入 Redis；
- 服务重启后，checkpointer 可以从 Redis 恢复已有 snapshot。

### Redis 未启动时

- 查询缓存自动降级为 miss；
- 外部请求照常执行；
- checkpointer 自动回退 `InMemorySaver`；
- 服务可以正常启动和对话，只是不具备 Redis 缓存和跨重启恢复。

### Redis 写入失败时

- 缓存写入失败只记录 warning；
- checkpointer 写入失败只记录 warning；
- 当前进程内存状态继续可用。

## 遗留事项

1. 当前 Redis-backed checkpointer 是项目内轻量适配器。

   它适合本地 Docker Redis 演示和轻量持久化。如果后续进入生产部署，建议评估官方 `langgraph-checkpoint-redis` 或 Postgres checkpointer。

2. Checkpoint 当前以整体 snapshot 方式保存。

   会话数量较大时，单 key snapshot 可能变大。后续可以按 thread_id 拆分 key。

3. 失败结果未缓存。

   这避免缓存临时故障，但重复失败请求仍可能继续访问外部服务。后续可以为明确的业务空结果设计短 TTL 负缓存。

4. 前端暂不显示缓存命中或 Redis 降级状态。

   第七阶段做前端体验优化时，可以结合 `progress` / `degraded` 事件展示缓存命中和降级提示。
