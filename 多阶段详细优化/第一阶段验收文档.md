## 本阶段完成范围

### 1. 新增公共工具模块

新增文件：

- `tools/base.py`

提供能力：

- `ok(data)`：统一成功返回结构；
- `fail(message, detail=None, retryable=False)`：统一失败返回结构；
- `request_json_with_retry(...)`：统一 HTTP JSON 请求、超时、重试和错误包装；
- `get_tool_logger(...)`：工具日志对象；
- `configure_logging_from_env()`：按 `LOG_LEVEL` 配置日志级别；
- `summarize_params(...)`：低风险参数摘要；
- `is_retryable_http_status(...)`：临时 HTTP 状态判断。

### 2. 统一工具返回协议

所有本阶段涉及的外部工具统一返回：

成功时：

```python
{
    "success": True,
    "data": {},
    "error": None,
}
```

失败时：

```python
{
    "success": False,
    "data": None,
    "error": {
        "message": "错误码",
        "detail": "错误详情",
        "retryable": False,
    },
}
```

### 3. 改造外部工具

已改造文件：

- `tools/locations.py`
- `tools/nearby.py`
- `tools/transportation.py`
- `tools/web_search.py`
- `tools/attractions.py`

完成内容：

- 高德相关请求统一使用 `params` 参数，不再手动拼完整 URL；
- 高德相关请求统一使用 `12s` 超时；
- 网络超时、连接错误、临时服务错误按策略重试；
- 业务错误、空结果、参数错误不盲目重试；
- 缺少环境变量返回统一失败结构；
- 工具层不再使用 `print` 输出调试信息；
- 日志只输出到控制台；
- 日志级别由 `LOG_LEVEL` 控制，默认 `INFO`；
- 日志不记录 API key、完整 URL 和完整用户消息。

### 4. 周边 POI 参数错误处理

已按最终确认方案处理：

当 `keyword == ""` 且 `types == ""` 时，`tools/nearby.py` 不再抛出 `ValueError`，而是返回：

```python
fail(
    "invalid_poi_query",
    "关键字和 POI 类型至少填写一个",
    retryable=False,
)
```

该错误被视为业务参数错误，不重试。

### 5. 景点抓取降级

`tools/attractions.py` 已完成稳定性改造：

- `MAX_SCENIC_SPOTS` 从 7 调整为 5；
- Selenium 启动、加载或页面结构解析失败时，不中断整体规划；
- Selenium 失败后降级调用 `web_search`；
- 降级结果在 `data` 中明确标记：

```python
{
    "source": "web_search_fallback",
    "fallback_used": True,
    "warnings": [...],
}
```

前端当前调试面板会展示工具输出，因此可以看到降级信息。

### 6. Prompt 适配

已小幅调整：

- `prompts/main.py`

新增“工具返回格式说明”，要求模型：

- `success=true` 时读取 `data`；
- `success=false` 时读取 `error.message` 和 `error.detail`；
- `retryable=false` 时不机械重复调用同样参数；
- `fallback_used=true` 时谨慎说明信息来源可能不完整；
- 不把失败结果当成真实旅游事实；
- 不暴露 API key、完整 URL 或内部堆栈。

### 7. 新增工具层测试

新增测试文件：

- `tests/test_tools_base.py`
- `tests/test_tools_locations.py`
- `tests/test_tools_nearby.py`
- `tests/test_tools_transportation.py`
- `tests/test_tools_web_search.py`
- `tests/test_tools_attractions.py`

测试覆盖：

- `ok` / `fail` 返回结构；
- HTTP 临时错误重试；
- HTTP 400 不重试；
- 缺少 `AMAP_API_KEY`；
- 高德坐标成功返回；
- 高德业务错误；
- 周边 POI 参数错误；
- 周边 POI 成功返回；
- 周边 POI 空结果；
- 路线规划成功但无公交方案；
- 路线规划业务错误；
- 搜索成功；
- 搜索空结果；
- Selenium 失败后触发 web_search 降级；
- 景点数量限制为 5。

3. 工具返回结构已改变，虽然 Prompt 已补充说明，但仍建议进行一次真实聊天手动验证。

   重点观察：

   - Agent 是否正确从 `data` 中读取工具结果；

   - `fallback_used=true` 时最终回复是否谨慎说明；

4. 当前日志只输出到控制台。

   文件日志、日志轮转、结构化 JSON 日志可放到后续产品化阶段。
