## 当前遗留事项

1. 当前测试没有覆盖真实外部 API 联调。

   后续如需上线前确认，应单独执行带真实 `AMAP_API_KEY` 的手动联调或集成测试。

2. `/chat/stream` 只覆盖接口结构和 NDJSON 响应，不覆盖真实模型输出。

   完整对话链路建议在后续阶段加入更高层的集成测试或端到端手动验收。

3. 当前项目只有 `requirements.txt`。

   如果后续需要区分生产和开发依赖，建议新增 `requirements-dev.txt`，将 `pytest` 等测试工具迁移过去。

4. 目前没有覆盖率统计和 CI 阶段。

   后续可以引入 `pytest-cov` 和 GitHub Actions / 本地脚本，避免测试只依赖人工运行。

## 后续建议

下一阶段可以进入结构化状态或 LangGraph 多节点重构。在开始重构前，应保持第二阶段测试全绿，确保后续改动不会破坏工具返回协议和 API 基础请求结构。
