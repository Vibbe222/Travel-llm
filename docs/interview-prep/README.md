# 旅游规划机器人面试准备材料

这组材料基于当前仓库真实实现整理，目标是帮助你把项目讲清楚、把追问答稳、把一周训练落地。

这套材料默认面向 Python 后端 + AI 应用方向面试，重点覆盖：

- 高频追问和反问场景

你可以把它当成 3 份可直接使用的成品：

- `7-day-plan.md`: 每天怎么练、练什么、练到什么程度
