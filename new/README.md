# `new/` 参考实现说明

这个目录是一套平行参考实现，用来展示如何把原项目中“`agent -> tools -> agent`”的两节点 LangGraph，拆成更清晰的多阶段业务图。

设计目标：

- 原项目目录和文件完全不动
- 在 `new/` 下镜像关键结构，方便逐文件对照
- 尽量复用原项目已有模型工厂和工具能力
- 更强调“分阶段职责、结构化状态、统一工具返回”

这不是原项目的替换版，而是一个设计草稿兼参考实现，适合：

- 面试时说明“如果生产化我会怎么拆”
- 对照学习从 demo 图到阶段化图的演进
- 作为后续正式重构的参考起点

核心变化：

- 单个万能 Agent 拆为多个业务节点
- 状态从只有 `messages` 升级为消息 + 业务字段
- Prompt 拆分为多个阶段 Prompt
- 工具统一包装为 `success / data / error` 结构

目录说明：

- `agents/`: 阶段型 LLM 执行器
- `graph/`: 图定义、节点逻辑、业务路由
- `prompts/`: 不同阶段的提示词
- `states/`: 结构化状态定义
- `tools/`: 对原工具的统一包装
- `chat_service.py`: 参考版图的独立调用入口
